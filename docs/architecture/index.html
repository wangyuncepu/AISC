3serve 帧协议（一条 SSH 会话上的多路复用）

所有帧都是单行 JSON（UTF-8），经 ssh 的 stdin/stdout 往返 —— 不开任何网络端口，SSH 认证即全部认证。

# 启动握手：版本配对（serve_protocol 硬门，cli_version 供展示）
← {"type":"ready","serve_protocol":1,"cli_version":"2.1.10.dev0"}

# 请求 / 响应：单帧承载完整 envelope（version / doctor / ps / fs.* / …）
→ {"id":"wb1","op":"fs.list","args":{"root":"/home/user/proj","path":"src"}}
← {"id":"wb1","type":"result","ok":true,"envelope":{…}}

# 终端流（每个会话一个 sid；输入/尺寸全带内）
→ {"type":"pty.input","sid":"…","data":"base64"}     → {"type":"pty.resize","sid":"…","cols":100,"rows":30}
← {"type":"pty.output","sid":"…","data":"base64"}    ← {"type":"pty.exit","sid":"…","exit_code":0}

# 事件推送（远端文件变更 → 本地变更面板实时联动）
← {"type":"event","event":"fs.change","data":{"root":"…","paths":[{"path":"…","change":"created"}]}}
