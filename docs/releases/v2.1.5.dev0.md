# AISC v2.1.5.dev0

> **预览版（preview）**：GUI Fine-Tune 阶段完成。仅发布 Windows 安装器。

## Workbench — GUI Fine-Tune 全部 18 个目标（G-01..G-18）完成

本版本完成 Workbench 桌面应用的 GUI Fine-Tune 全部 18 个目标，覆盖：

- **设置**：typed settings（G-01，对话框/校验/重置/即时生效/UI 字号缩放）、i18n 中英双语（G-09）。
- **终端**：渲染升级（G-06，WebGL 回退 DOM）、基础体验与右键菜单（G-03/G-11，搜索/剪贴板/清屏）、Resize 根因修复（G-02，交互会话改走 Docker SDK + 管道方案彻底绕过 ConPTY 编码/对齐问题）。
- **多任务**：动态多 tab（G-08，8 叶上限/重复类型/重开）、Tab 内分屏（G-17，PaneTree 分屏 + 拖拽/键盘 resize）。
- **状态与恢复**：侧边栏分层 + Provider 引导（G-05/G-12）、窗口尺寸/位置记忆（G-10）、动态窗口标题（G-15）、一键诊断（G-13）、构建最终耗时与通知（G-14）、停止/关闭/退出性能（G-07）。
- **系统集成**：CLI sidecar 入用户 PATH（G-18，NSIS 安装器）、可选最小化到托盘（G-16）、明暗主题（G-04，system/dark/light + 无闪屏）。
