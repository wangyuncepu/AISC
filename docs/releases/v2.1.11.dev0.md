# AISC v2.1.11.dev0

> **预览版（preview）**：v2.1.10-dev 封版后的第五个开发周期——主题「**传输统一收口 · Shell 对标 VS Code · Provider 模型热切换**」：本地与远程 CLI 通信彻底同轨（池化驻留 serve）、界面骨架全面向 VS Code 看齐（菜单栏 / 一窗一工作区 / 命令面板 / 设置页重构）、切换 provider 后运行中会话的下一个请求即走新模型。仅发布 Windows 安装器。

## 传输统一（S2，D-5 step 2）

- **本地全命令切池化驻留 serve**：本地与远程同池同闸门同驱逐语义，一处覆盖 28 个调用点、调用面零改动；每个操作省去 aisc.exe 冷启动税（实测冷 534ms / 热 10ms，原逐次 spawn ~1.4s）。
- **版本配对驱逐**：池条目记录 spawn 时 exe mtime，构建更新即自动驱逐重建；`--events` 通道兜底回落。
- **帧层健壮化**：zh-CN Windows 下 serve 帧 GBK 字节撕裂会话的根因修复（全 ASCII 逃义 + stdio UTF-8 双保险）；cli op 信封命令身份透传（本地远程同病一处修）。

## Shell 对标 VS Code（W1-W3 + P2 系列）

- **内嵌菜单栏**：操作 / 编辑 / 帮助三菜单，最近打开与远程机器均 VS Code 式二级悬浮（本地 / 远程分类徽章、双行条目）。
- **一窗一工作区**：一个工作区一个窗口，跨窗口切换交给操作系统；参数化启动直达工作区不闪选择页；按窗口隔离驱动目标——远程 / 本地窗口并开互不干扰；关窗先视觉收场、收尾后台推进。
- **命令面板**：Ctrl+Shift+P 呼出，注册表驱动、二级拆分子步骤；rail 图标化常驻 activity bar + Ctrl+B；topbar 整行退役。
- **设置页重构**：VS Code 式左侧导航 + 右侧内容 + 全文搜索；设置 / 数据看板降为浮窗（随 UI 字号缩放）。
- **反馈语法统一**：全局 Toast 原语（底部居中、进度形态、随字号缩放）；空态全带行动入口。

## Provider 体验与模型热切换（P1 + P3）

- **API key 显隐**：已配置密钥默认占位隐藏，眼睛按钮按需取回明文（密钥仅经 stdin 通道，列表恒掩码）。
- **模型热切换（传输层 shim）**：容器内模型映射 shim 占据历史端口，按「当前 provider 的角色映射表」重写请求体 model 字段——切换 provider 后**运行中会话的下一个请求即走新模型**，无需重启会话；shim 失效自动退化为直连（连通性永远优先）。
- **热切换配套修复**（手测十轮连破五案）：拉取模型 401（行密钥被官方 live 同步污染——行自有密钥优先）；「default」幽灵卡片清扫；跨容器世代的端口陈旧自愈；Rust 边界字段透传（映射回显 / 上游格式不再被默认值改坏——曾致 codex 全线断流）；codex 三方互切密钥同步（worker 只在启用时刻捕获令牌——切换舞步在 disable 与 enable 之间同步行密钥）。
- **实际模型可见**：切换提示与当前卡片显示「实际模型」；官方直连卡品牌图标（Claude / OpenAI）；模型映射表可增删、四盒对齐。
