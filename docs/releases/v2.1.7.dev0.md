# AISC v2.1.7.dev0

> **预览版（preview）**：v2.1.6-dev 封版后的第一个开发周期——主题「上手体验与运行可感」：构建看得懂、失败说得清、首次启动不再莫名超时、界面语言彻底统一；并按用户裁决收敛安装边界（Docker 自装）。仅发布 Windows 安装器。

## 构建体验（进度可见 · 可取消 · 断网可建）

- **构建进度条 + 百分比**：构建工作站镜像改为进度优先视图——百分比、阶段、步骤计数实时更新；完整原始日志折叠可展开，并可一键在文件管理器中定位磁盘日志。百分比诚实规则：缓存命中转不确定态动画而非假 100%、上下文传输用上次构建日志估算分母（封顶 95%）、无进度阶段不编造数字。兼容 BuildKit 与 legacy 双日志格式。
- **构建取消**：随时可取消，Windows 下按进程树终止（docker 子进程不残留）；取消后如实显示「已取消」。
- **等待预期**：构建全程显示「初次构建通常需要 10–20 分钟，增量构建几分钟」的耗时提示。
- **断网/网络受限也能建（宽容性）**：构建所需的 cc-switch 版本解析按四级递进——在线解析 → 新鲜缓存 → 上次成功解析的本地回执（任意年龄）→ **继续无钉版构建**（Dockerfile 自动从国内镜像源下载，进度区显著警示「本次未钉版、不保证可复现」）。`--require-pin` 可恢复严格模式。解析失败类错误全部显示真实原因（如「无法访问 GitHub（网络受限）」+ 完整指引），不再是一句「AISC CLI 返回错误」。

## 启动体验

- **首次启动 180 秒就绪预算**：工作区首次启动（冷缓存）需要解压镜像层并初始化容器环境，弱机上常超旧的 60 秒上限——冷启动自动放宽到 180 秒并显示「仍在启动，最长约 3 分钟」提示；稳态启动保持 60 秒快速失败。
- **Docker 未就绪不再笼统阻断**：Docker 引擎未启动时启动工作区，直接落在启动摘要页——显示未通过的检查项、提供「启动 Docker」唤起与自动重试，而非一句「启动已被阻断」；真冲突（其他实例占用/归属不明）的阻断页也内联显示后端原因。
- **未安装 Docker 时**：显示自行安装指引（官网或可信渠道），安装后自动识别；程序内不再提供一键安装。

## 首跑与工作区管理

- **首跑直入选择页**：启动不再弹引导向导，直接选工作区；环境检测后移到选定工作区之后按需触发；向导保留在设置页入口。
- **工作区历史**：首页最多 8 条 + 展开更多；右键删除单条；点击前校验路径存在性，失效路径只清记录、绝不动用户文件。
- **彻底忘记工作区**：单事务移除（容器/运行时停止删除 + 数据根内工作区内容清理 + 历史摘除，失败自动回滚）；租约占用或归属不明时拒绝执行并说明原因。

## 资源管理器与「变更」面板

- **变更徽章体系**：类型（＋新增 / ✎修改 / −删除 / ⇄移动）× 来源（实底=Agent 登记、虚线框=系统检测）统一徽章，图标+文字+悬停说明；`mv` 改名如实呈现（旧路径计删除、新路径计移动，Agent 登记的移动显示真实旧路径）。
- **「产物」页签更名「变更」**。
- **顶部搜索**：文件/变更共享 VSCode 式搜索框——字面子串、模糊跳字、`/正则/` 三模式（非法正则自动回退）；变更面板另有分类筛选与可收拢分组。
- **性能**：千文件级工作区秒开（索引指纹门控跳过无变化重扫）；轮询按值门控，无变化不再触发重绘。

## 终端

- **上手教学**：首屏按 agent 显示速查卡；内置 `help` 命令；练习全部免费可验证，产生用量的命令明确标注。
- **粘贴修复**：Ctrl+Shift+V 不再偶发粘贴两份（按键释放事件被重复处理所致）。
- 黑框闪现修复（打开文件/探测子进程补 `CREATE_NO_WINDOW`）。

## 预配置 Provider（cc-switch）

- **全部 codex 预置供应商的上游格式统一为 OpenAI Responses API（原生直连）**，本地路由不再做协议转换；DeepSeek 按官方文档切至 Responses 端点。
- **新增 Codesome-Group 预置**：codex `https://cc.codesome.ai`（默认模型 gpt-5.6-sol）、claude `https://v5.codesome.cn/api`；密钥永不出厂，用户自填。
- **codex `/model` 模型目录**：各预置自带目录（智谱 glm-5.3 / Kimi k3 / Codesome gpt-5.6-sol，窗口按官方文档）；且**切换供应商时实时拉取该供应商最新模型列表**合并进目录——厂商发新模型自动可见，无需等版本更新（离线或端点不支持时自动回退静态目录）。
- Provider 页底部改为常显操作指引；官方/直连占位行保持隐藏。
- 存量容器在下次启动时自动刷新预置行（版本化迁移，用户自定义值不覆盖）。

## 界面语言

- **中文界面全量清扫**：模板硬编码、中文词典内的英文值、后端枚举裸渲染（就绪状态/取消状态/门禁类别）全部本地化；「运行时：新建 Runtime」类费解行移出界面（日志保留）。

## 已知限制

- 嵌套虚拟化（Hyper-V VM）低分辨率下轮询闪烁仍未根治（真机无复现，专项排查挂起）。
- WSL2 机器可能出现系统级端口段幽灵保留导致工作区启动报「无可用网关端口」：管理员执行 `wsl --shutdown` 后 `netsh int ipv4 add excludedportrange protocol=tcp startport=47000 numberofports=1000` 根治（详见文档）。
- 沿袭 v2.1.6.dev0 其余已知限制，逐步消化中。
