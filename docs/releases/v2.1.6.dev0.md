# AISC v2.1.6.dev0

> **预览版（preview）**：v2.1.5-dev（GUI Fine-Tune 收口）之后的完整增量——aisc-next 七阶段架构演进（Stage 0-6）、Windows 数据根（Stage 7）、cc-switch Provider 管理（Stage 8 + IDEA-4）、启动/Tab 小项轮，另含 IDEA-3 3a 内部重构（无行为变化）。仅发布 Windows 安装器（在线版：缺失 Docker Desktop 时经 winget 自动安装）。

## 工作区资源管理器与 Agent 产物（Stage 3）

- **资源管理器侧栏**：工作区目录树懒加载实时刷新（变更 watcher 驱动），文件/目录右键操作，忽略集与临时文件过滤，键盘无障碍树导航（APG）。
- **Agent 产物面板**：agent 在容器内产生的文件/目录自动归因（`aisc.artifact/v1` 契约 + artifact 索引），与资源管理器联动展示；未归因变更兜底投影。
- **内置 Artifact Skill**：容器内 agent 可调用的产物记录技能。

## 安装与首次引导（Stage 5）

- **引导向导**：环境检查（Docker/WebView2 三根检测）→ 工作区 → agent 就绪 → 网络代理（容器 TUN）→ runtime 预检的完整首跑流程；完成页可从设置重新打开。
- **一键 Docker 安装**：缺失 Docker Desktop 时 onboarding 内经 winget 引导安装（进度 + toast 通知）；离线安装包形态保留。
- **NSIS→Workbench 交接**：安装器完成页拉起 Workbench 并传递状态。

## UI / 无障碍 / 诊断（Stage 6）

- **设计令牌**：间距/字号/圆角/阴影/层级/动效时长统一 token 化；Compact/Standard/Wide 三档响应式布局。
- **无障碍**：对话框焦点陷阱 + 还原、reduced-motion 尊重、菜单键盘导航。
- **诊断**：操作耗时环形缓冲 + 脱敏诊断包一键导出；顶栏状态与会话状态全面 i18n。
- **兼容**：settings/onboarding/artifact 旧版本 schema fixture 迁移测试（升级不丢配置）。

## Windows 数据根（Stage 7）

- 数据统一收敛至 `%LOCALAPPDATA%\AISC\data`（工作区配置/产物注册表/app 状态/诊断）；旧布局自动扫描 + 迁移（prepare/copy/commit + 回滚 + 损坏隔离），`aisc data-root doctor/migrate/rollback` CLI 可自查自修。
- 容器 project 态从数据根挂载 `workspaces/<h>/{claude,codex,cc-switch,runtime}`；**镜像成为容器脚本唯一事实源**（宿主覆盖桥移除）。

## cc-switch Provider 管理与切换（Stage 8 + IDEA-4）

- **Provider 管理页**（新 tab）：cc-switch 供应商增删改查 + 密钥掩码脱敏；DeepSeek 官方预设（官方 endpoint/模型映射，ownership 规则：用户覆盖保留、预设升级自动跟进）。
- **一键切换**：点击条目即切换到该代理；使用中条目再点可取消代理、回官方直连；codex 侧自动开/关本地代理路由，并修复 Codex CLI 自身首跑登录向导误触发（无密钥占位，真实登录永不触碰）。
- **cc-switch latest stable resolver**：镜像构建解析 latest stable（当前 v5.10.1，GitHub digest 做 sha256 权威源 + OCI labels），CI 离线 manifest 兜底。
- **CLI**：`aisc cc-switch list|add|edit|switch|delete`（密钥仅经 stdin 传递，stdout 零回显）。

## 终端与多任务（Stage 1 + GUI 收尾）

- 终端输出链路重写：**有界批量缓冲 + 分帧 flush**（高频输出不再卡顿/冻屏），滚动缓冲截断可见可回放；PTY 失败路径有代际守卫（陈旧会话事件不污染新会话）。
- Ctrl+Tab / Ctrl+Shift+Tab 循环切换 tab；开发端口避开 Windows 排除区段。

## CLI 双轨与分发（Stage 2）

- pip CLI 与安装器 sidecar **双轨一致性**（契约 fixture 对拍、JSONL 深比较、能力矩阵、无尘安装冒烟）；sidecar 清洁室升级 + 原子回滚；依赖 SBOM/审计（脱敏）。
- 契约统一 `aisc.cli/v1` envelope，三方（Python/Rust/TS）共享 fixture。

## Docker 网关（Stage 4）

- Python `DockerGateway`：SDK/Cli/Auto 三后端工厂，application 不感知后端；**交互会话（agent 终端）改走 Docker SDK** exec 生命周期（绕过 ConPTY 编码/对齐问题）；Build 后端经基准测试决策保持 CLI（p50/p95 数据留档）。

## 启动与 Tab 体验（IDEA-1/KI-1 小项轮）

- **Tab UX**：设置页 tab 化并铺满窗格；`+` 拆分按钮（默认新 tab 类型可在设置中配置）+ `▾` 完整菜单；`+` 菜单不再被滚动容器裁剪。
- **Docker 静默唤起**：已安装未启动场景一键静默唤起 Docker Desktop（不再弹 Dashboard）；向导/摘要页显示连续进度与就绪提示；引擎探测细节可诊断。

## 基线与安全（Stage 0）

- 三语契约 fixture 基线、密钥 denylist 矩阵（Bearer/OAuth 脱敏）、控制面资源预算冻结 + soak 用例。

## 内部（IDEA-3 3a，无用户可见变化）

- Workbench 状态机抽为 per-工作区 WorkspaceRuntime 工厂 + runtime store 门面（为多工作区 tab 层级铺路）；全部既有测试零改动通过（另加门面契约测试）。
