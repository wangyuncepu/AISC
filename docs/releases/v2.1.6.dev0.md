# AISC v2.1.6.dev0

> **预览版（preview）**：v2.1.5-dev（GUI Fine-Tune 收口）之后的完整增量——aisc-next 七阶段架构演进（Stage 0-6）、Windows 数据根（Stage 7）、cc-switch Provider 管理（Stage 8 + IDEA-4/5）、多工作区/订阅用量/生命周期日志等 followup 完整增量，以及收官三波：终端稳定性专项（B-05）、容器内 Web 服务访问、**会话级运行时与 Docker 资源全生命周期重构**。仅发布 Windows 安装器（在线版：缺失 Docker Desktop 时经 winget 自动安装）。

## 会话级运行时与工作区生命周期（体验重构）

- **全新运行时模型**：每次启动 Workbench 都使用新创建的会话级容器，退出/关闭即停止并删除——不再积累长期驻留容器，也从根上移除了「工作区被其他运行时占用」的冲突处置页。
- **工作区租约**：多 Workbench 实例并存时以文件租约仲裁归属（15s 心跳 / 45s TTL，由原生侧守护写入而非前端定时器，托盘隐藏/休眠唤醒均可靠）；异常残留的运行时在下次启动 reconcile 时自动回收。
- **三级资源归属**：所有 AISC 创建的容器/镜像携带 `io.aisc.*`/`org.aisc.*` 所有权标签；无法确认归属的同名/相似资源只报告、永不删除——升级与卸载清理只作用于可证明自有的资源。
- **懒布局恢复**：上次会话的页签布局以休眠占位形式恢复，激活时才真正拉起运行时；关闭占位页只是历史摘除，零副作用。
- **持久工具链**：Agent 安装的用户级 npm/pip/cargo 工具跨容器、跨会话保留（挂载 `/opt/aisc/toolchain`，Windows 真机基准达标）；卸载时可独立勾选清除。

## Docker 资源全生命周期（安装 / 升级 / 卸载一致化）

- **升级（含维护页重装）**：自动停止并删除 AISC 容器 → 以新 bundle **无缓存重建工作站镜像**（分钟级，日志可见进度语言）→ 成功后清掉被替换的旧镜像。Docker 不在线时应用文件照常更新，镜像重建转为待办并在完成页给出手动命令；离线环境从本地缓存钉版 cc-switch，确定性重建不依赖 GitHub 可达。
- **卸载**：默认清理 AISC 自有容器与工作站镜像；归属不明资源仅列表不删除，非 AISC 容器/镜像、卷和网络一律不碰。工具链目录与应用数据是相互独立的勾选项，默认保留；需要彻底清理按需勾选，命令行 `/KEEPDOCKER` 等价于取消 Docker 勾选。
- **维护 CLI**：`aisc maintenance docker-scan|docker-cleanup|docker-rebuild`——安装器与人工排障走同一套服务与冻结退出码（0 成功 / 3 Docker 不可达 / 1 部分 / 2 用法错误）；scan 提供机器可读 JSON 与稳定文本两种形态。
- **通道覆盖**：NSIS 主安装器、Inno 备选安装器、Windows/macOS/Linux 便携脚本、macOS PKG 内嵌卸载器全部同语义；19 条安装器静态契约纳入测试门禁，Windows 真机完成全新安装/重装升级/完整卸载/引擎离线卸载四象限冒烟。
- **CLI 检测加固**：PATH 接管/冲突探测按注册表句柄指针宽度实现并增加"读取失败绝不改写"防线（安装器在任何情况下不会破坏既有用户 PATH）。

## 终端稳定性专项（B-05）

- 三症根因收口：长输入不再同行覆盖、窗口缩放后尺寸即时自适应（含失败自愈）、快速切换 tab 不再行错乱；发送串行化消除竞态乱序。
- 渲染护栏：窄窗 TUI 双侧钳位与提示层、切换/新建/缩放统一过渡动效、就稳即达防抖；flex 收缩导致的阶梯式挤压修复。

## 容器内 Web 服务访问

- 每个 runtime 一个宿主回环网关端口；容器内服务经 `aisc-web-expose <port>` 注册后即可从宿主浏览器访问，URL 形如 `http://p<port>.localhost:<host>/`。
- HTTP/WebSocket 字节级原样转发不改写；Workbench「服务」面板一键打开已注册入口；旧版运行时优雅降级并标注原因。

## 工作区资源管理器与 Agent 产物（Stage 3）

- **资源管理器侧栏**：工作区目录树懒加载实时刷新（变更 watcher 驱动），文件/目录右键操作与拖拽插入终端（容器路径 + POSIX quoting），忽略集与临时文件过滤，键盘无障碍树导航（APG）。
- **Agent 产物面板**：agent 在容器内产生的文件/目录自动归因（`aisc.artifact/v1` 契约 + artifact 索引），与资源管理器联动展示；未归因变更兜底投影。
- **内置 Artifact Skill**：容器内 agent 可调用的产物记录技能。

## 安装与首次引导（Stage 5）

- **引导向导**：环境检查（Docker/WebView2 三根检测 + 引擎探测详情可诊断）→ 工作区 → agent 就绪 → 网络代理（容器 TUN）→ runtime 预检的完整首跑流程；完成页可从设置重新打开。干净环境首跑验证通过（CLI 发现零竞态）。
- **一键 Docker 安装**：缺失 Docker Desktop 时 onboarding 内经 winget 引导静默安装；离线安装包形态保留。
- **NSIS→Workbench 交接**：安装器完成页拉起 Workbench 并传递状态。

## UI / 无障碍 / 诊断（Stage 6）

- **设计令牌**：间距/字号/圆角/阴影/层级/动效时长统一 token 化；Compact/Standard/Wide 三档响应式布局。
- **无障碍**：对话框焦点陷阱 + 还原、reduced-motion 尊重、菜单键盘导航。
- **诊断**：操作耗时环形缓冲 + 脱敏诊断包一键导出；顶栏状态与会话状态全面 i18n。
- **兼容**：settings/onboarding/artifact 旧版本 schema fixture 迁移测试（升级不丢配置）。

## Windows 数据根（Stage 7）

- 数据统一收敛至 `%LOCALAPPDATA%\AISC\data`（工作区配置/产物注册表/app 状态/诊断）；旧布局自动扫描 + 迁移（prepare/copy/commit + 回滚 + 损坏隔离），`aisc data-root doctor/migrate/rollback` CLI 可自查自修。
- 容器 project 态从数据根挂载 `workspaces/<h>/{claude,codex,cc-switch,runtime}`；**镜像成为容器脚本唯一事实源**（宿主覆盖桥移除）。

## cc-switch Provider 管理与切换（Stage 8 + IDEA-4/5 + KI-7）

- **Provider 管理页**（新 tab）：cc-switch 供应商增删改查 + 密钥掩码脱敏；DeepSeek 官方预设（官方 endpoint/模型映射，ownership 规则：用户覆盖保留、预设升级自动跟进）。
- **一键切换**：点击条目即切换到该代理；使用中条目再点可取消代理、回官方直连；codex 侧自动开/关本地代理路由，并修复 Codex CLI 自身首跑登录向导误触发（无密钥占位，真实登录永不触碰）。
- **五槽模型映射**：编辑表单内嵌（MODEL/OPUS/SONNET/HAIKU/SUBAGENT 五键显式写，空=删键）；`[1m]` 声明开关；拉取模型三级降级（拉取 ∪ 已知清单 ∪ 手动输入）；切换反馈三件套（行脉冲/chip 过渡/toast，reduced-motion 退化）。
- **CLI**：`aisc cc-switch list|add|edit|switch|delete|fetch-models`（密钥仅经 stdin 传递，stdout 零回显）。

## 多工作区与工作区层（IDEA-3）

- **多工作区并存**：多个工作区容器同时运行；顶部双层条（工作区条 + 页条），工作区 chip 显示文件夹名（同名才显全路径）；关闭工作区即时摘除并后台静默收尾；历史合并保存。
- **设置工作区层**：设置从对话框升级为工作区层 tab（Ctrl+,，`+ ▾` 可配默认新页）；`ui.default_new_page`。
- **快捷键**：Ctrl+PgUp/PgDn 页切换、Ctrl+Alt+数字直达；watcher 事件带路径过滤 + 资源管理器 per-path 缓存。
- **首跑 CLI 发现竞态修复（KI-3 根因）**：negotiate 推迟导致的「找不到 aisc cli」假报根除；stale pin 自愈（存在性检查 + 自动重发现写回）。

## 订阅与用量（IDEA-2 + 挂账①②）

- **mihomo 订阅导入**：URL 与粘贴内容双模式（密钥仅走 stdin）；刷新后订阅哈希进 fingerprint（proxy 模式自动引导重建容器）。
- **Rust 下载器（挂账①）**：reqwest+rustls + clash 家族 UA + WinINET 系统代理，捕获 `subscription-userinfo` 头；Python 传输保底回落。
- **假节点名用量兜底（挂账②）**：机场把套餐事实伪装成节点名（已用/剩余/总量/到期）时正则提取，头优先、无总量不报。
- **「网络与用量」面板**：订阅用量条/余量/到期 + Provider token 统计（全工作区聚合，k/M 自动单位与 USD/CNY 切换）；向导内嵌表单 + 启动摘要警示。

## 终端与多任务（Stage 1 + GUI 收尾）

- 终端输出链路重写：**有界批量缓冲 + 分帧 flush**（高频输出不再卡顿/冻屏），滚动缓冲截断可见可回放；PTY 失败路径有代际守卫。
- Ctrl+Tab / Ctrl+Shift+Tab 循环切换 tab；开发端口避开 Windows 排除区段。

## Docker 网关与容器随镜像同步（Stage 4 + KI-4 挂账）

- Python `DockerGateway`：SDK/Cli/Auto 三后端工厂，application 不感知后端；交互会话走 SDK exec 生命周期；Build 后端经基准测试决策保持 CLI（数据留档）。
- registry 记录镜像 ID（内容寻址）；同 tag 重建镜像后旧容器不再被复用——启动时弹出引导重建；存量记录自动补档（无假冲突）。

## 全流程生命周期日志

- `<数据根>/logs/aisc.log` 单一 JSONL 时间线（2MB×3 轮转），一条 run_id 串「UI 操作 → CLI 调用 → 容器操作」全链。
- **`aisc logs show/path`** 命令（--lines/--source/--format）；诊断对话框「最近日志」折叠段 + 一键复制；诊断包附日志尾与 managed 容器 `docker logs` 尾随。
- UI 动作打点带成败与错误码；「无法沟通 aisc CLI」全族时间线可见。

## 已知限制

- **一键安装 Docker 无进度反馈**：winget 静默路径期间界面仅有静态提示，慢网络下最长约 10 分钟后才会给出结果或超时（改进已排期）。
- **低分辨率 / 弱 GPU 环境（含嵌套虚拟机）下可能出现周期性闪烁**：状态轮询触发的全树重绘在软件渲染下可见；功能不受影响，加大虚拟机显示分辨率可缓解。
- **Windows 打开资源管理器文件、向导安装 Docker 时可能闪现黑色控制台窗**：两处子进程缺"不建窗"标志（修复已排期）。
- **嵌套虚拟化 / 极慢磁盘冷启动首开工作区可能超时报错**：预算固定 60 秒；重开即恢复正常，失败实例会被生命周期自动清理。
- Windows 正式发布需代码签名/公证（未配置）。
- macOS/Linux 安装通道本版仅静态契约 + CI 编译验证，未做实机矩阵。
