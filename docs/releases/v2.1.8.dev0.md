# AISC v2.1.8.dev0

> **预览版（preview）**：v2.1.7-dev 封版后的第二个开发周期——主题「**Agent 历史对话管理** + **Bash 体验增强**」：工作区内的 Agent 会话可查、可续、可管；内建终端换装 zsh，补全、高亮、历史即时落盘一步到位。仅发布 Windows 安装器。

## Agent 历史对话

- **独立「历史」页签**（文件 → 历史 → 变更 → 服务）：列出当前工作区的全部 Claude / Codex 历史会话——标题取自你的真实输入（自动跳过注入的 AGENTS.md/技能上下文与 SDK 内部消息）、按最近排序、支持搜索；含消息数与 agent 归属标注。
- **一键恢复对话**：左键点击即在新标签页恢复该会话（`claude --resume` / `codex resume`）；恢复前先做预校验（会话文件精确匹配），文件已删/ID 无效时行内提示原因，不产生空标签页。
- **活会话不重复开**：同一会话已有活标签页时，再次点击直接切换过去——provider 拒绝对进行中的会话二次恢复，不再出现"开了新页就报错"。
- **右键管理**：打开 / 重命名 / 删除。重命名写工作区级标题覆盖（重启后保留，provider 自身标题不受影响）；删除带确认框，精确删除该会话文件并同步刷新列表。
- **列表永不发霉**：切到历史页签或点刷新按钮都会强制重扫本地会话文件，新会话即时出现。
- 不可恢复的会话如实标注（文件过大 / 部分损坏），不再无声消失。

## 终端体验（bash 标签页全面升级）

- **zsh + 幽灵文本**：终端标签页内建 zsh——输入时灰色建议随行提示（→ 接受）、实时语法高亮（合法/错误着色）、Tab 智能补全；自带彩色提示符。
- **历史即时落盘**：每条命令执行完立刻写入工作区历史——关标签、强退都不会丢；新开标签按 `↑` 可召回上次会话的全部命令。
- **SQLite 会话账本**：工作区内所有终端命令（含会话 ID、目录、退出码）落库，跨标签持久，为后续工作台功能打底。
- **常用工具预装**：yazi（文件管理器，文本/代码预览）、neovim、ripgrep、fzf 余量保留、tmux；`procps`/`file` 补齐（前者曾导致终端增强加载失败，后者曾导致 yazi 预览永远转圈）。
- **构建网络兜底强化**：ble.sh 等 GitHub 资源预下载进镜像（国内镜像对部分资产返回 HTML 的坑已绕开）；构建期下载失败不再静默产生"缺能力"的镜像。

## 安装器与镜像

- **镜像重建即生效**：工作区启动时检测镜像内容变更，提示移除旧运行时重建，不再默默用旧容器。
- 国内网络环境下 apt/npm/GitHub 资产三级镜像与预下载兜底（v2.1.7 延续并加固）。

## 已知限制

- **幽灵文本要求 Nerd Font**：yazi 图标与终端图标字形需要安装 [JetBrainsMono Nerd Font](https://github.com/ryanoasis/nerd-fonts)（设置 → 终端字体填入 `JetBrainsMono Nerd Font Mono`）；未安装时自动回退系统字体，仅图标显示为方块。
- ble.sh（bash 幽灵文本方案）在 Workbench 终端链路上会冻结 shell，已默认停用并改由 zsh 方案交付同一能力；兼容性专项挂账中。
- 变更页对 Codex 产出文件的归因仍显示为"未归因修改"（沿袭问题，专项优化挂账）。
- 嵌套虚拟化（Hyper-V VM）低分辨率下轮询闪烁仍未根治（沿袭 v2.1.7）。
- WSL2 机器端口段幽灵保留的根治方案沿袭 v2.1.7（`netsh int ipv4 add excludedportrange …`）。
