# AISC v2.1.9.dev0

> **预览版（preview）**：v2.1.8-dev 封版后的第三个开发周期——主题「**远程工作区 · 宿主工具 · 低配机性能**」：SSH 远程工作区双向同步、容器内 Agent 调用宿主工具（MCP）、低配置机器 Docker 性能专项（空闲 / 冷启动 / 启动终端全面提速）。仅发布 Windows 安装器。

## 远程 SSH 工作区（F1）

- **SSH 远程工作区**：本地 Workbench 直连远程目录开发——mutagen 双向同步（MIT 授权版本），影子目录即真工作区，身份链零改动。
- **多 profile 并存**：`~/.ssh/config` 受管分节，多台远程机各自记忆，互不覆盖。
- **按需拉取 + 浏览钉根**：远端文件浏览器只允许浏览工作区根之内；大目录可先开工作区再增量拉取。
- **排除规则**：`*.bin` 等模式过滤，超大文件不进同步。
- **取消 / 恢复同步**：一键暂停（后台终止传输），一键恢复续传。
- **磁盘防护三层**：传输前容量预估警示、剩余空间低于 2GiB 自动暂停同步、恢复与新建门槛校验。

## 容器内 Agent 调用宿主工具（F2 宿主 MCP）

- **宿主 MCP 服务**：容器内的 claude / codex 可调用宿主白名单工具（如 git 只读查询），带 token 鉴权与 cwd 钉死，密钥永不落盘。
- **注入链**：新会话自动注册 `aisc-host` MCP 服务器；claude（.mcp.json）与 codex（config.toml）幂等合并，用户已有配置不受影响。
- **mihomo TUN 对策**：代理 TUN 模式下的 DNS 劫持收窄方案，宿主回环可达。

## 低配机性能专项（PERF）

- **空闲不再拖卡整机**：稳态轮询改为 Rust 进程内直连 Docker 引擎——空闲时不再每 5 秒拉起 `aisc.exe`/`docker.exe` 进程链（活跃单工作区从每小时约 600 次进程创建降到稳态零）。
- **启动终端 / Agent 提速**：会话生命周期的 Docker API 调用从每秒 5 次降到近零；provider 检测修复后，启动工作区即刻打开 claude / codex 页 1-3 秒进入会话。
- **容器内三件套**：shell 命令历史批量落盘（每命令一次 Python 启动 → 每约 20 条一次）、环境注入缓存命中零进程、后台巡检快检。
- **冷启动**：容器内 daemon 就绪等待去 spawn 化（实测 1.8 秒）+ 启动脚本合并；新工作区首开明显提速。
- **低配模式**：≤8GB 内存机器自动开启——容器资源限额（`--memory`/`--cpus`）+ `.wslconfig` 保键合并（自动只补缺失，用户已有键不覆盖），开启时弹窗告知。
- **轮询自适应**：后台工作区 / 失焦窗口自动降频，慢引擎自动拉长间隔，快机器行为不变。

## Provider 页对标 cc-switch 桌面端（PP）

- Provider 管理页八轮手测收敛：预设快速添加 / 自定义双模式、模型映射三档位（含 1M 长上下文后缀）、上游格式切换（Anthropic / OpenAI Responses / Chat 转换）、实时模型目录拉取。

## 体验优化（O1-O9）

- 分屏被滚动条遮挡修复、终端输出截断改磁盘 spool 按需回放、Provider 切换链重构提速、冷启动出厂增量复制、构建缓存清理产品化（磁盘页）、构建网络韧性硬化（预拉镜像链 + 离线逃生）。

## 修复与质量

- 挂账清偿：隔离测试修复、ble.sh 移除、#3 归因修复（呈现降级为朴素列表）、VM 闪烁三轮收敛。
- 设置页卡死根治（P8 分节渲染断链）、tauri 插件版本对齐、历史记录转义解码单遍化（含字面 `\t` 序列）。
- SDK 执行器行为对齐（exec 双流分离、模板回退语义）、低配内存配置双端校验。

## 已知限制

- **幽灵文本需要 Nerd Font**：zsh 图标与 yazi 图标需要 [JetBrainsMono Nerd Font](https://github.com/ryanoasis/nerd-fonts)（设置 → 终端字体填 `JetBrainsMono Nerd Font Mono`）；未安装时自动回退系统字体。
- **长对话恢复**偶发失败（独立 bug，专项挂账）。
- **分屏键盘导航**（`Ctrl+Shift+hjkl`）在 WebView2 浏览器加速器层被拦截，封存（`Ctrl+Shift+W` 关闭分屏可用）。
- F1 冲突双副本列表投影待真实冲突样本；SSH 密码认证暂不支持（仅密钥）。
- 低配模式容器限额只影响**新建**的容器；`.wslconfig` 合并生效需重启 WSL（应用内会提示）。
- 嵌套虚拟化（Hyper-V VM）低分辨率环境轮询闪烁未根治（沿自 v2.1.7）。
