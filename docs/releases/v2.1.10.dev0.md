# AISC v2.1.10.dev0

> **预览版（preview）**：v2.1.9-dev 封版后的第四个开发周期——主题「**CLI 远程化（VS Code Remote 式）+ 工作区体验补全**」：一台 Workbench 驱动多台远程机器的容器工作区（serve 长驻通道）、远端文件浏览、CLI 命令族与 Workbench 互通、面板拖动折叠。仅发布 Windows 安装器。

## CLI 远程化 R1-R4（VS Code Remote 式）

- **serve 长驻通道**：`aisc serve --stdio` 帧协议（握手配对 CLI 版本），Workbench 与远程机的全部会话/文件/事件流走单条 SSH 长连接——不再每个操作一次 SSH 握手。
- **远程终端会话**：远程工作区开箱即用——bash / claude / codex 会话全走远端 PTY 流，分屏 / resize / 查找与本地一致。
- **远端文件面**：远端权威模型——资源管理器直接浏览远端目录（懒展开 / ignore 等价 / 新建 / 重命名 / 删除），远端文件变化实时刷新（watcher 全链）；「打开」走远端临时副本 + 本地软件。
- **机器管理页 + 网关端口转发**：设置页管理远程机器档案（增删改 / 重启保留）；选择工作区页一键切换驱动机器（本机 / 远程徽章 / 跨机最近列表自动切换）；远程容器 Web 服务经同端口 SSH 隧道直达浏览器。

## FIX-2 远程体验补全 + CLI 命令族

- **控制面迁 serve（实测 10 倍）**：远程机器上的全部控制操作（列表 / 探活 / 切换）从每次一次 SSH 握手（281ms）降到 serve 帧往返（27ms）；两端版本自管，远端过旧给明确升级指引。
- **远端目录浏览器**：新建远程工作区不再手敲路径——浏览弹层钉根 `$HOME`，单击选中 / 双击进入，隐藏目录可切换，模糊搜索。
- **CLI run 解耦**：`aisc run <路径>` 激活工作区（detached 常驻）；`aisc claude` / `aisc codex` 顶层入口（活跃工作区容器内直达，参数透传）；`aisc stop` 停删（`--all` 批量、Workbench 运行时不碰）；`aisc runs` 历史 + `--resume <别名|序号|路径>`；`aisc workspaces` 机器级视图（join 别名 + Docker 状态 + 批量清场）。
- **同工作区幂等激活**：重复 `run` 不堆容器——在跑即复用（提示进入方式），改名单即重建，死容器自动清尸；GUI 与 CLI 所有权互不越界。

## CLI 体验

- **tab 补全**：接入 argcomplete（bash / zsh / fish），子命令 / 参数 / 候选值三层提示。
- **help 随系统语言**：中文系统看中文 help（输出层翻译，英文为唯一源）；错误文案中文化（含下一步指引）。
