## A. Explorer 拖宽（右缘 6px 把手）

- [ ] **A1 跟手**：拖动把手，宽度实时跟随指针——无 300ms 追赶滞后、
      无跳跃；240/600 夹停
- [ ] **A2 zoom 免疫**：设置 font_scale 1.5 拖一次；再把窗口压窄
      （<800px，scale 被 clamp）拖一次——把手与指针不脱节/不过冲
- [ ] **A3 终端单次重排**：松手后 veil 单次淡出，无逐步挤压阶梯
- [ ] **A4 键盘**：把手可 Tab 聚焦（focus ring），←/→ ±8px

## B. Explorer 折叠（VS Code 式窄条）

- [ ] **B1 三入口**：Explorer 工具栏 « 按钮 / 双击把手 → 平滑收到
      40px 窄条（**不得卡在 240px**）；窄条 » 或再双击 → 展开回原宽
- [ ] **B2 状态保活**：展开树几个目录 + 滚到中部 → 折叠再展开——
      树展开态与滚动位置保留；搜索框输入内容保留
- [ ] **B3 持久化**：拖到自定义宽 + 折叠 → 重启 Workbench → 三态恢复
      （宽/折叠/tab 高）；清 localStorage（键 `aisc-wb-panel-layout-v1`）
      后回默认 320/展开/自然高
- [ ] **B4 终端无振荡**：单次折叠/展开 + 单次平滑拖动全程 fitDiag
      自诊断浮层不弹（若弹，记时间点——阶梯式慢拖的合法计数与振荡
      环路靠浮层日志行区分）

## C. TabBar 分界线（标签行与终端之间）

- [ ] **C1 拖高**：上下拖 6px 分界线，标签行高度 40..120 夹停；

- [ ] **C2 溢出**：开 8+ 个 tab，横向滚动正常；↑/↓ 键盘 ±4px
