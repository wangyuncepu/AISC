## Windows 手动测试

### 1. 前提

- Windows 10 或 Windows 11；
- 在项目根目录运行 PowerShell；
- Python 可以执行本项目代码；
- 不需要管理员权限；
- 脚本只操作 `%TEMP%` 下新建的测试目录，不应接触真实密钥。

### 2. 执行命令

```powershell
$TS = Get-Date -Format "yyyyMMdd-HHmmss"
$OUT = "$env:TEMP\aisc-s5.3-smoke\$TS"

python tests/manual/smoke_s5_3_windows.py --output-dir "$OUT"

Write-Host "EXIT=$LASTEXITCODE"
Get-Content "$OUT\smoke_evidence.json"
```

脚本自身会定位仓库的 `src` 目录，通常不需要手动设置 `PYTHONPATH`。

### 3. 测试内容

| 项目 | 说明 | 通过条件 |
|---|---|---|
| Q1 正常使用 | 创建包含 Unicode 和空格的安全目录及私密文件，并写入、读取数据 | `PASS` |
| Q2 权限复验 | 再次验证已存在目录的 Windows DACL；`icacls` 只作为观察信息 | `PASS` |
| Q3 junction 拒绝 | 创建指向测试目录外部的 junction，确认公开 API 拒绝，并且外部数据未变化 | `PASS` |
| Q4 碰撞安全 | 同名文件已存在时必须报 `FileExistsError`，原内容不能改变 | `PASS` |
| Q5 fd 关闭 | 返回有效 fd，关闭后 `os.fstat(fd)` 必须失败 | `PASS` |

### 4. 如何判断结果

#### 通过

期望控制台结尾类似：

```text
[Q1-normal-use] PASS
[Q2-permission-sanity] PASS
[Q3-junction-rejection] PASS
[Q4-collision-safety] PASS
[Q5-fd-hygiene] PASS
OVERALL: PASS
EXIT=0
```

`smoke_evidence.json` 应包含：

```json
{
  "schema_version": "s5.3-personal-smoke-1",
  "overall": "PASS"
}
```

#### 环境阻塞

若系统不允许创建 junction，Q3 可能为 `BLOCKED`，整体退出码为 `2`。这不是功能通过，也不一定表示程序存在 bug。请保留完整控制台输出和 JSON。

#### 失败

任一项目为 `FAIL` 时，整体退出码为 `1`。不要用真实密钥继续测试；请保存：

1. 完整控制台输出；
2. `$OUT\smoke_evidence.json`；
3. `python --version`；
4. `[System.Environment]::OSVersion.Version`。

## 测试后的清理

脚本会清理其工作子目录，并将清理错误视为失败。证据目录可在检查后手动删除：

```powershell
Remove-Item -LiteralPath "$OUT" -Recurse -Force
```

只有在 `smoke_evidence.json` 已保存或不再需要时才执行该命令。

## 范围限制

该测试针对当前实际接线的公开 API，适合回答“个人日常使用是否基本正常”。它不证明：

- retained-handle 后端已经接入公开运行路径；
- 所有 Windows TOCTOU 或 namespace race 已被关闭；
- 已达到生产级密钥存储安全标准；
- 所有 Windows SKU、文件系统和企业策略均兼容。

因此，即使五项全部通过，也只应得出“当前 Windows 环境下个人使用冒烟通过”的结论。
