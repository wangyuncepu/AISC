# Superpowers

Select the workflow under `skills/` that best matches the task, then read its
complete `SKILL.md` before acting.

Prefer the smallest applicable workflow. Typical routes include:

- New design or feature: `skills/brainstorming/SKILL.md`
- Bug diagnosis: `skills/systematic-debugging/SKILL.md`
- Implementation from a plan: `skills/executing-plans/SKILL.md`
- Test-first development: `skills/test-driven-development/SKILL.md`
- Completion checks: `skills/verification-before-completion/SKILL.md`
- Code review: `skills/requesting-code-review/SKILL.md` or
  `skills/receiving-code-review/SKILL.md`

Follow the selected child skill's instructions exactly.
