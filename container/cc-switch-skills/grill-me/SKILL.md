# Grill Me

Interview the user relentlessly about every aspect of the plan, decision, or
idea until both sides reach a shared understanding.

Walk down each branch of the decision tree and resolve dependencies between
decisions one by one. For every question, provide a recommended answer.

Ask exactly one question at a time and wait for feedback before continuing.

If a fact can be discovered from the environment, inspect it instead of asking.
The decisions remain the user's: present each decision and wait for confirmation.

Do not implement the plan until the user confirms that the shared understanding
is complete.
