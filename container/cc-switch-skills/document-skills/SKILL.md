# Document Skills

Route the task to the matching bundled skill under `skills/` and read that
skill's complete `SKILL.md` before acting.

Common routes:

- Word documents: `skills/docx/SKILL.md`
- Spreadsheets: `skills/xlsx/SKILL.md`
- Presentations: `skills/pptx/SKILL.md`
- PDFs: `skills/pdf/SKILL.md`
- Collaborative drafting: `skills/doc-coauthoring/SKILL.md`
- Visual or web artifacts: select the closest matching skill under `skills/`

Follow the selected child skill's instructions and reuse its scripts and assets.
